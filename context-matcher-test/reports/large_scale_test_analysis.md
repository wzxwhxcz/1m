### 💡 改进建议

#### 1. 话题感知的召回策略

```python
def adaptive_k_by_topic_size(topic_percentage: float, base_k: int = 50) -> int:
    """根据话题规模自适应调整k值"""
    if topic_percentage < 10:
        return base_k * 2  # 小话题召回2倍数量
    elif topic_percentage < 20:
        return int(base_k * 1.5)  # 中话题召回1.5倍
    else:
        return base_k  # 大话题保持不变
```

**预期效果**: Git话题召回准确率从40% → 60%+

#### 2. 子话题聚类


## 🎓 核心学习

### 1. 话题规模是关键

**发现**: 话题占比<10%时，召回准确率显著下降（40% vs 82%）

**启示**: 在真实场景中，需要监控话题分布，对小话题类别进行特殊处理

### 2. MRR vs Precision的权衡

**发现**: MRR=1.000（完美），但Precision@50=73.2%（良好）

**启示**: CAR在"找到首个相关消息"方面完美，但在"召回所有相关消息"方面还有提升空间

### 3. 复杂度不等于性能

**发现**: 极高复杂度查询（82%）反而比高复杂度查询（68%）表现更好

**启示**: 模糊开放查询可能更容易匹配多个话题，反而召回率更高
