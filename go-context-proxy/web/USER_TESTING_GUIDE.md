### Ant Design 弃用警告
浏览器控制台会显示以下警告（不影响功能，可以后续优化）：

```
Warning: [antd: Statistic] `valueStyle` is deprecated. Please use `styles.content` instead.
Warning: [antd: Progress] `trailColor` is deprecated. Please use `railColor` instead.
Warning: [antd: message] Static function can not consume context like dynamic theme.
```

这些是 Ant Design 5.x 的 API 升级警告，不影响页面显示和功能。
